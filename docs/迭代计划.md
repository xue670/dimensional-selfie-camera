# 版本迭代计划

## 总体策略

基于当前原型状态和实际开发复杂度，建议采用“主版本 + 修复版本 + 能力版本”混合推进，而不是只按大阶段粗放划分。

原因：

1. 相机、合成、保存属于闭环基础能力，必须先稳定。
2. 角色锚定、互动反馈、美颜分别依赖不同技术路径，适合拆开迭代。
3. 手机端真实体验很容易被小问题放大，因此需要保留修复版本节奏。

当前建议按以下顺序推进。

## 正式版本 V0.1 - 自拍合影 MVP

### 目标

证明核心体验成立：用户可以在手机端打开相机，导入一个角色，并完成自拍合影。

### 当前状态

已完成首版原型，并已通过 GitHub + Vercel + HTTPS 真机访问跑通主链路。

### 已交付内容

1. 前置摄像头预览。
2. 2D 图片导入。
3. 3D 模型导入（GLB）。
4. 角色基础摆放：
   - 移动
   - 缩放
   - 旋转
5. 基础待机动画效果。
6. 快门拍照与图片导出原型。

### 当前遗留问题

1. 预览效果与最终成片不一致。
2. 图片角色位置在预览与成片中存在偏移。
3. 本地保存体验不完整。

## 修复版本 V0.1.1 - 成片一致性修复

### 目标

修复已经影响自拍闭环的关键问题，让“看见什么、拍到什么、存下什么”保持一致。

### 修复内容

1. 修复预览与拍照合成结果不一致的问题。
2. 修复 2D 图片角色在导出中的坐标偏移问题。
3. 统一预览层与导出层的尺寸、缩放、镜像逻辑。
4. 优化拍照后的结果反馈。

### 成功标准

1. 用户预览中的角色位置与最终成片保持一致。
2. 不再出现明显的镜像、偏移、比例错位。
3. 自拍结果可作为继续迭代的稳定基线。

## 修复版本 V0.1.2 - 3D 导入兼容性修复

### 目标

打通手机端 3D 模型选择与导入链路，确保 `GLB` 在常见安卓设备上可被实际选中并导入。

### 修复内容

1. 修复移动端无法选中 `GLB` 文件的问题。
2. 拆分图片导入与 3D 模型导入入口。
3. 优化安卓文件选择器对非媒体文件的兼容行为。
4. 增加导入失败提示与 3D 导入说明。

### 成功标准

1. 用户能在常见安卓设备上选中并导入 `GLB` 文件。
2. 3D 模型导入不再被系统误导向相机或照片入口。
3. 3D 主流程真正可用。

## 修复版本 V0.1.3 - 本地保存与分享修复

### 目标

补齐手机端“拍完就能保存”的基础能力。

### 修复内容

1. 增加可用的本地保存流程。
2. 针对 Android / iPhone 优化保存提示。
3. 条件允许时接入系统分享。
4. 明确保存失败时的回退方案。
5. 修复成片中真人画面比例异常或压缩感问题。
6. 修复切出网页再返回后相机预览卡住的问题。
7. 优化保存结果与预览分辨率不一致的问题。

### 成功标准

1. 用户无需额外摸索即可完成保存。
2. 保存后的图片与预览结果一致。
3. 不依赖开发者解释即可完成自拍闭环。
4. 页面切后台再返回后，相机能尽量自动恢复或明确提示重启。

## 正式版本 V0.2 - 移动端交互增强

### 目标

把当前“能用原型”提升为“手机上顺手可用的拍摄工具”。

### 交付内容

1. 优化手机端按钮布局和层级。
2. 优化导入、重置、拍照反馈。
3. 增强 2D / 3D 的移动端操作体验。
4. 改善角色默认入场位置与默认大小。
5. 降低误触与界面遮挡。

### 成功标准

1. 单手操作更顺畅。
2. 用户能更快完成导入与拍摄。
3. UI 不再明显像技术原型。

## 正式版本 V0.3 - 角色锚定版

### 目标

让角色不再只是“浮在画面上”，而是开始稳定地贴合真人自拍构图。

### 交付内容

1. 固定角落锚定：
   - 右下角
   - 左下角
   - 侧边陪伴位
2. 肩部附近吸附：
   - 基于轻量人体关键点或画面布局估算
   - 让角色更像挂在肩侧或靠在肩边
3. 锚定与手动微调共存。
4. 减少角色在画面中的漂移感。

### 范围说明

V0.3 优先做“看起来合理”的轻量方案，不追求高精度 AR 骨骼绑定。

### 成功标准

1. 角色能稳定停留在预期区域。
2. 自拍结果更像同框合影，而不是贴纸悬浮。
3. 用户能明显感觉到“角色有位置关系”。

## 正式版本 V0.4 - 意识感增强版

### 目标

让角色从“位置稳定”进一步升级为“会陪你自拍的对象”。

### 交付内容

1. 角色注视镜头。
2. 更自然的待机动作参数化。
3. 拍照前倒计时动作。
4. 拍照成功后的角色反馈动作或表情。
5. 更自然的前后层级和遮挡表现。

### 成功标准

1. 用户能明显感受到角色“在回应我”。
2. 自拍截图更像合影，而不是贴纸叠加。

## 正式版本 V0.5 - 动作互动版

### 目标

让角色开始对用户动作做出有限但明确的反馈，形成“突破次元壁”的核心记忆点。

### 交付内容

1. 基于用户动作的轻互动反馈：
   - 用户用手指指向角色时触发回应
   - 角色做出头部轻蹭、靠近、轻微表情反馈等动作
   - 用户动作离开后回到待机状态
2. 扩展简单触发动作：
   - 招手
   - 靠近镜头
   - 轻点角色区域
3. 建立“动作输入 -> 角色反馈”的映射规则。

### 范围说明

V0.5 优先做“有限动作识别 + 角色反馈映射”，不在本阶段扩展成完整行为 AI。

### 成功标准

1. 用户能通过简单动作感受到角色对自己行为的回应。
2. 互动反馈自然、轻量，不抢自拍主流程。
3. 产品开始具备差异化记忆点。

## 正式版本 V0.6 - 角色资产增强版

### 目标

提升资产兼容性和角色表现力。

### 交付内容

1. 更稳的 3D 资源加载与错误提示。
2. 多种 2D 呈现模式：
   - 平面立绘
   - Q 版立牌
   - 悬浮挂件
3. 预设姿势与拍照模板。
4. 角色场景滤镜与边缘融合优化。
5. 更灵活的导入配置与角色预设。

### 成功标准

1. 用户能更方便地导入自己的 OC 或喜欢的角色。
2. 结果图更适合直接分享。
3. 资产兼容性更稳定。

## 正式版本 V0.7 - 基础美颜版

### 目标

在不破坏角色叠层和性能的前提下，为真人自拍部分补上轻量美颜能力。

### 交付内容

1. 轻度磨皮。
2. 肤色均衡。
3. 基础提亮。
4. 美颜强度开关或轻量分级。

### 范围说明

V0.7 的美颜只做轻量基础版本，优先保证：

1. 自拍观感更自然。
2. 不破坏角色叠层效果。
3. 不引入明显性能抖动。

### 成功标准

1. 基础美颜可提升人物上镜效果，但不过度改变原始面貌。
2. 角色叠层与自拍主体融合更自然。
3. 中端手机上依然可接受。

## 正式版本 V0.8 - 分享与沉浸版

### 目标

把产品从自拍工具提升为内容创作工具。

### 交付内容

1. 照片模板。
2. 简易连拍。
3. 分享页导出。
4. 项目内角色收藏夹。
5. 更好的性能与移动端适配。

### 成功标准

1. 用户愿意反复使用。
2. 用户愿意保存多个角色资产。
3. 输出内容具备社交传播价值。

## 后续可选方向

1. 视频模式。
2. 实时语音陪伴。
3. VRM / Live2D 生态接入。
4. 高精度人体关键点与空间锚定。
5. 原生 App 化。
