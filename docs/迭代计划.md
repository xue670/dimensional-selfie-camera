# 版本迭代计划

## 总体策略

采用四阶段迭代：

1. 先验证最小闭环。
2. 再提升角色真实感与互动感。
3. 再增强资产能力与分享能力。
4. 最后根据用户反馈决定是否进入原生化或 AI 陪伴化。

## V0.1 - 自拍合影 MVP

### 目标

证明核心体验成立：用户可以在手机端打开相机，导入一个角色，并完成自拍合影。

### 交付内容

1. 前置摄像头预览。
2. 2D 图片导入。
3. 3D 模型导入（GLB）。
4. 角色基础摆放：
   - 移动
   - 缩放
   - 旋转
5. 基础待机动画效果。
6. 快门拍照与图片导出。

### 成功标准

1. 用户可在 3 分钟内完成首次导入与自拍。
2. 拍照结果中角色与真人同框自然。
3. 手机浏览器下主要流程可用。

## V0.2 - 意识感增强版

### 目标

让角色从“贴图/模型”升级为“陪你自拍的对象”。

### 交付内容

1. 角色注视镜头。
2. 待机动作参数化。
3. 拍照前倒计时动作。
4. 拍照成功后的角色反馈动作或表情。
5. 更自然的前后层级和遮挡表现。

### 成功标准

1. 用户能明显感受到角色“在回应我”。
2. 自拍截图更像合影，而不是贴纸叠加。

## V0.3 - 角色资产增强版

### 目标

提升资产兼容性和角色表现力。

### 交付内容

1. 更稳的 3D 资源加载与错误提示。
2. 多种 2D 呈现模式：
   - 平面立绘
   - Q 版立牌
   - 悬浮挂件
3. 预设姿势与拍照模板。
4. 角色场景滤镜与边缘融合优化。

### 成功标准

1. 用户能更方便地导入自己的 OC 或喜欢的角色。
2. 结果图更适合直接分享。

## V0.4 - 分享与沉浸版

### 目标

把产品从自拍工具提升为内容创作工具。

### 交付内容

1. 照片模板。
2. 简易连拍。
3. 分享页导出。
4. 项目内角色收藏夹。
5. 更好的性能与移动端适配。

### 成功标准

1. 用户愿意反复使用。
2. 用户愿意保存多个角色资产。
3. 输出内容具备社交传播价值。

## 后续可选方向

1. 视频模式。
2. 实时语音陪伴。
3. VRM / Live2D 生态接入。
4. 面部追踪驱动角色互动。
5. 原生 App 化。
